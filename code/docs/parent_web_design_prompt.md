> 이 문서는 **Claude(디자인)에게 그대로 붙여넣는 프롬프트**다.
> 아래 `── 프롬프트 시작 ──` ~ `── 프롬프트 끝 ──` 사이를 복사해 사용한다.
> **첨부 필수**: 디자인 전공이 작업한 Figma 화면 **스크린샷 이미지** + (가능하면) 폰트/색상이 보이는 컷.
> 작동은 필요 없음 — **시각 디자인(목업)만** 만든다.

---

## ── 프롬프트 시작 ──

너는 시니어 프로덕트 디자이너다. **SIA**(시각장애 유아 AI 보행 교육 파트너) 서비스의
**부모용 모바일 웹 화면**을 디자인한다. 코드 동작은 필요 없고 **시각 디자인 목업**만 만든다.

### 0. 산출물 (이것만 만든다)
- **모바일 우선(세로 390×844 기준)** 정적 화면. 동작 로직 없음.
- 형식: 단일 `index.html` + 내부 `<style>` (외부 의존성 0, 더미 데이터 하드코딩).
  - WebSocket·API·카메라 실연결 금지. 카메라/그래프/알림은 **목업 이미지·더미 텍스트**로 표현.
- 화면 4개를 한 페이지에 세로로 이어 붙여 **시안 보드**처럼 보여줘
  (① 홈/모니터링 ② 실시간 보행 ③ 대화/활동 기록 ④ 빠른 도움). 각 화면 위에 작은 캡션 라벨.
- 데스크탑은 범위 밖. **모바일 디자인만**. (데스크탑 대시보드와 별개 화면)

### 1. 디자인 규격 = 첨부 이미지/Figma가 **유일한 정답지**
- 함께 첨부한 **Figma 스크린샷 이미지**에서 색상·폰트·로고·일러스트·아이콘 톤을 **그대로 추출해 적용**한다.
- 첨부에 있는 폰트가 우선. 웹폰트가 불가하면 가장 가까운 시스템 폰트로 대체하고 주석으로 표기.
- 아래 "폴백 토큰"은 **첨부 이미지가 불충분할 때만** 쓰는 임시값이다. 첨부와 충돌하면 **첨부가 이긴다.**

```
/* 폴백 토큰 (현재 데스크탑 대시보드 기준 — 첨부 규격으로 덮어쓸 것) */
--pink-primary: #F4A7A7;   /* 주 강조 */
--pink-light:   #FDE8E8;
--pink-bg:      #FFF5F5;
--cream-bg:     #FAF0E6;   /* 배경 */
--text-primary: rgba(40,30,20,0.85);
--text-secondary: rgba(60,50,40,0.6);
--green: #4CAF50;  /* 정상/연결 */
--blue:  #2196F3;  /* 진행/생각중 */
--red:   #E53935;  /* 위험 */
--radius: 12px;
브랜드: 제품명 "시아(SIA)", 따뜻하고 부드러운 파스텔, 둥근 모서리, 유아 교육 친화적 톤.
```

### 2. 톤 & 사용자
- 사용자는 **시각장애 유아의 부모**. 전문 운영자가 아니다 → 용어를 쉽게, 안심을 주는 카피.
- 따뜻함·신뢰·안전감. 큰 터치 영역(최소 44×44px), 큰 본문, 충분한 대비(WCAG AA).
- 위험 알림은 분명하되 **공포가 아니라 보호받는 느낌**으로.

### 3. 반드시 포함할 기능 (현재 데스크탑 대시보드 기능을 부모용으로 재구성)
> 아래는 운영자용 대시보드의 실제 기능이다. **기능은 유지하되, 부모가 보는 화면의 언어/구성으로 번역**한다.

| 대시보드(운영자) 기능 | 부모용 화면에서의 표현 |
|---|---|
| 연결 상태(초록/빨강) + 세션 경과 타이머 | 상단에 "시아 연결됨 ● / 오늘 보행 12:34" 같은 안심 상태 배지 |
| 3단계 진행(StageStepper: 수용→방향→기술) | 우리 아이의 학습 단계 진행 바 (1 수용 · 2 방향 · 3 기술), 현재 단계 강조 |
| 실시간 카메라 피드(CameraView) + 단계 라벨(LIVE/REC) | "지금 아이가 보는 길" 라이브 카드(목업 이미지) + 상태 칩 |
| 방향 감지(DirectionPanel: 왼쪽/정면/오른쪽 객체) | 좌·정면·우 3분할 "주변 상황" 표시 (예: 정면 1.2m 사람) |
| 실시간 대화(ChatPanel: 아이 발화/시아 응답/내레이션) | 말풍선 채팅 타임라인 ("아이: 앞에 뭐 있어?" / "시아: 앞에 의자가 있어") + 시각 |
| 음성 상태(STTInput: 대기/인식중/생각중/시아가 말하는중) | 하단 음성 인디케이터 (상태별 색·펄스 도트, 라벨) |
| 위험 감지(danger, Stage 3) | 위험 시 상단 경고 배너/카드 (빨강, 부드러운 카피: "잠깐! 앞에 계단이 있어요") |
| 세션 제어(새 세션 / 단계 전환 / 정지) | "보행 시작 / 단계 바꾸기 / 종료" 부모용 버튼 (확인 다이얼로그 톤) |
| 수동 오디오(FallbackPanel 6종) | 빠른 도움 버튼: 멈춰! · 앞에 뭔가 · 잘하고 있어 · 잠깐만 · 시작 · 끝 (큰 그리드) |

### 4. 화면별 구성 가이드
**① 홈/모니터링**
- 헤더: 시아 로고/아바타, 연결 상태 배지, 오늘 보행 시간.
- 학습 단계 진행 바(3단계).
- "지금 아이가 보는 길" 카메라 미리보기 카드(목업) → 탭하면 ②로.
- 오늘 요약 카드(보행 시간, 칭찬 횟수, 위험 회피 횟수 같은 더미 지표).

**② 실시간 보행**
- 큰 카메라 카드(목업) + 상단 상태 칩(REC·기술 단계·감시 중).
- 주변 상황 3분할(좌/정면/우)과 거리 텍스트.
- 위험 발생 시 상단에 경고 배너(빨강) 예시 1컷 포함.
- 하단 음성 인디케이터("시아가 말하는 중…" 상태).

**③ 대화·활동 기록**
- 말풍선 채팅 타임라인(아이/시아 구분 색), 타임스탬프, 내레이션/칭찬/위험 메시지 섞어서.
- 메시지 타입 색 구분: 위험=빨강, 내레이션=파랑 계열, 시아 응답=핑크.

**④ 빠른 도움 (부모 개입)**
- 6개 큰 버튼 그리드(멈춰!/앞에 뭔가/잘하고 있어/잠깐만/시작/끝).
- 세션 제어(보행 시작·단계 바꾸기·종료) 영역.

### 5. 작업 절차
1. 먼저 **첨부 이미지에서 색/폰트/아이콘/일러스트 톤을 추출**해 디자인 토큰을 정의(주석으로 출처 표기).
2. 위 4개 화면을 모바일 세로 폭으로 정적 HTML+CSS 목업으로 그린다(더미 데이터).
3. 다 그린 뒤, 추출한 토큰과 각 화면이 대시보드 어떤 기능을 담았는지 **짧은 표로 요약**.
4. 코드 동작/실연결은 만들지 말 것. **보이는 디자인이 전부.**

### 6. 금지/주의
- 실제 카메라·WebSocket·마이크 연결 코드 금지(전부 목업).
- 첨부 규격을 무시하고 임의 색/폰트 쓰지 말 것(폴백은 부족할 때만).
- 운영자 전문 용어 노출 금지(예: "broadcast", "stage 3", "fallback")는 부모 친화 표현으로.
