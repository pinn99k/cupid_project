## 구성 요소

| 구성 | 역할 |
|---|---|
| ESP32-CAM + 초음파 센서 | 카메라 영상(MJPEG) 스트리밍, 앞쪽 장애물 거리 측정. 판단은 하지 않음 |
| 노트북 서버 (FastAPI) | 영상 수신, 객체 탐지, 음성 대화, 위험 판단, 대시보드 중계 |
| 골전도 이어폰 + 마이크 | 아이에게 시아의 음성 전달, 아이의 말 입력 |
| React 대시보드 | 운영자·관람객용 화면: 카메라 영상, 대화 자막, 학습 단계 제어 |

## 흐름

**비전 루프**
1. 서버가 ESP32-CAM 영상을 받아 YOLOv8n으로 객체를 탐지합니다.
2. 객체의 위치를 왼쪽 / 가운데 / 오른쪽으로 나누고, 최근 프레임 다수결로 결과를 안정화합니다.
3. 초음파 거리가 기준보다 가까우면 위험 경고를 먼저 말합니다.

**음성 루프**
1. 마이크 입력을 VAD로 끊어 텍스트로 바꿉니다 (Google 음성인식 또는 로컬 faster-whisper).
2. 호출어 "시아야"가 있으면 뒤쪽 질문만 뽑습니다.
3. 학습 단계와 최신 장면(YOLO 탐지 결과를 문장으로 바꾼 것)을 붙여 LLM에 질문합니다. LLM은 이미지를 직접 보지 않습니다.
4. 답을 문장 단위로 나눠 TTS로 말하고, 대시보드에 자막으로 보냅니다.

**안정성 장치**
- LLM 타임아웃과 실패 쿨다운, 미리 만든 폴백 음원
- 오류 유형별 되묻기 (목소리 작음 / 인식 불가 / 호출만 함)
- 단계 전환·세션 리셋 시 이전 장면과 오디오 상태 초기화
