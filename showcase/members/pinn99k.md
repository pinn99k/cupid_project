## 해결한 문제

### 1. 오래 켜 둬도 안 죽는 실시간 서버
- **상황**: 탐지 루프(YOLO), 음성 루프(STT → LLM → TTS), 대시보드 통신이 한 서버에서 동시에 돕니다.
- **해결**: 카메라 프레임과 장면 결과를 락으로 보호한 "최신 1개" 슬롯에 담고, 읽을 때는 복사본을 넘겼습니다. 그래서 루프끼리 서로 기다리지 않습니다. 단계를 바꾸거나 세션을 리셋하면 이전 장면을 비워서, 지난 탐지 결과가 새 대답에 섞이지 않게 했습니다.
- **결과**: 부스 시연에서 서버를 끄지 않고 약 3시간 연속 운영했습니다.

### 2. 흔들리는 YOLO 결과 안정화
- **상황**: 프레임마다 탐지 결과가 바뀌어 "왼쪽에 사람"과 "오른쪽에 사람"이 번갈아 안내됐습니다.
- **해결**: 최근 5프레임 동안 (물체, 방향) 조합을 다수결로 투표해서, 2번 이상 나온 것만 안내했습니다. 작거나 먼 물체는 관련성 게이트로 무시했습니다. 아이가 질문하면 YOLO를 다시 돌리지 않고, 신선도 검사를 통과한 최신 장면으로만 답했습니다.

```python
# 최근 5프레임에서 (label, direction)이 2번 이상 나온 객체만 채택
for idx, scene in enumerate(scenes):
    for obj in scene.get("objects", []):
        key = (obj["label"], obj["direction"])
        votes.setdefault(key, {"count": 0, "obj": obj})
        votes[key]["count"] += 1
stable = [v["obj"] for v in votes.values() if v["count"] >= 2]
```

### 3. 아이 말을 잘 알아듣는 음성 UX
- **호출어**: STT가 "시아야"를 "시야", "씨아", "sia" 등으로 적는 문제를 후보 목록으로 흡수했습니다. "러시아"처럼 단어 중간에 들어간 경우는 걸러냈습니다.
- **STT**: 로컬 faster-whisper 경로를 추가해 Google 음성인식과 설정으로 전환할 수 있게 했습니다. 부스 소음에 맞춘 적응형 VAD를 넣고, 침묵 판정 시간을 늘려 말끝이 잘리지 않게 했습니다.
- **되묻기**: 오류를 "목소리가 작음 / 인식 불가 / 호출만 함"으로 나눠 다르게 되물었습니다. 시스템 오류일 때 아이에게 "다시 말해줘"라고 잘못 묻지 않게 했습니다.
- **TTS**: 공급자 우선순위를 두고(기본 Edge-TTS), 캐시와 프리웜으로 첫 응답 지연을 줄였습니다. 문장 단위로 끊어 말하고 자막으로 표시했습니다.
